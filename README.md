# Maira Khan — Portfolio

Personal portfolio of Maira Khan — Frontend Developer, UI/UX Designer & AI Video Creator.

Static HTML site styled with Tailwind CSS, with light and dark themes.

## Develop

```bash
npm install
npm run dev     # rebuilds assets/css/tailwind.css on change
npm run build   # minified production CSS
```

Theme colors live at the top of `src/input.css` (`--c-*` variables).
